## 4. Proposed IA / sitemap and route tree

**Unchanged routes** (renaming = URL change; none planned):

```
app/
  _layout.tsx                    root Stack + auth gate + onboarding gate (logic frozen)
  (tabs)/_layout.tsx             NativeTabs: Sessions · Desktops · Settings   (keep 3 tabs)
  (tabs)/(sessions)/index.tsx    Sessions list
  (tabs)/(desktops)/index.tsx    Desktops
  (tabs)/(settings)/index.tsx    Settings
  (tabs)/(settings)/appearance.tsx
  new-session.tsx                modal sheet
  pair.tsx                       modal sheet (QR / code)
  session/[id].tsx               session detail
  watch/[chatId].tsx             Watch Live
  sign-in.tsx
```

**Screen-by-screen intent**

- **Sessions** — native large-title + native search bar (`headerSearchBarOptions`), sections *Needs input* (status `awaitingInput`) → *Working* → *Recent* → *Archived* (collapsed). Row = harness mark · title · meta line (desktop · branch · relative time) · trailing status glyph; swipe actions (archive / open desktop) with `accessibilityActions`. Empty/offline/connecting/signed-out states as first-class layouts. FlashList kept.
- **Session detail** — transparent native header with inline title + status pill; transcript stays markdown + tool groups; tool groups get collapse-by-default with running group auto-expanded; sticky "needs your input" banner when an unresolved `input` part exists; composer becomes a glass bottom bar (26 radius) with attachment tray and steer/stop as segmented actions. Long-running / completed / failed states surfaced in header.
- **New session** — native sheet (`presentation: 'formSheet'`, detents medium/large), desktop picker → harness picker (`@expo/ui` Picker/menu) → prompt; disabled state with reason when no desktop online.
- **Desktops** — card per desktop: name, OS glyph, Online/Offline/Connecting, last seen; primary CTA "Link a desktop" → pair sheet. Signed-out variant explains Woozlit.
- **Pair** — sheet: camera viewport with glass overlay + 6-char code field; every failure message from the frozen flow surfaced verbatim in a Notice.
- **Settings** — grouped inset list (`@expo/ui` where it renders correctly, RN fallback otherwise): Account (avatar, sign-out — logic unchanged), Appearance, Notifications, About (version/edge host), "Show the welcome again".
- **Sign-in / Onboarding** — keep new aurora onboarding; sign-in gets the same backdrop, single Woozlit CTA, privacy line.
- **Global status** — one `ConnectionBanner` (connecting / offline / desktop offline / reconnecting) fed only from existing `ConnectionInfo` — no new data.
- **Accessibility / motion** — Dynamic Type via `allowFontScaling` + `maxFontSizeMultiplier` review; Reduce Motion gates all Reanimated decorative motion; Reduce Transparency already handled in `resolveTheme`; labels/roles/states on every icon-only control; 44pt targets.
